# ColourWay — новая концепция сайта

Полный редизайн сайта рекламного производства ColourWay Design. Бордовый первый экран, белые страницы, типографика Geometria и фотографии с действующего сайта. Логотип использует знак с оригинального сайта ColourWay.

## Содержание

- Адаптивная главная страница во втором дизайн-варианте. Пять фотографий на ней не повторяются в каталоге проектов и на остальных основных страницах.
- Отдельные страницы «Проекты», «Услуги», «О нас» и «Контакты» с общей навигацией.
- 12 проектов, карусель фотографий, фильтры по направлениям, подробный просмотр и навигация с клавиатуры.
- Карточки портфолио плавно появляются и исчезают при прокрутке; линия этапов оформлена как маршрут со стрелками.
- 8 групп услуг с раскрывающимися описаниями.
- Русская, узбекская и английская версии, сохранение выбранного языка в браузере.
- Страница «Заказать»: выбор изделий, индивидуальный проект, интерактивный макет с несколькими элементами и отправка заказа менеджеру через Telegram-бота. Ссылки из услуг и портфолио подставляют нужное направление.
- Мобильное меню, нативные диалоги, поддержка клавиатуры и reduced motion.
- Единая длительность переходов 0,8 секунды: прокрутка по разделам, окна, меню, фильтры, услуги, проекты и язык. Ручная прокрутка прерывает автоматическую; системная настройка reduced motion отключает анимации.

## Запуск

Сайт использует Cloudflare Worker для приёма заявок и `dist/client` для статических файлов. Сборка: `node scripts/build-worker.mjs` (она обновляет страницы из `scripts/build-v2-pages.mjs`). Проверка серверной части: `node --test tests/custom-order.test.mjs tests/lead-worker.test.mjs`.

В управляемой среде Sites используется штатный `sites-preview`, когда доступен браузерный маршрут.

## Файлы

- `dist/index.html`, `dist/projects.html`, `dist/services.html`, `dist/contact.html` — главная и отдельные страницы.
- `dist/about.html`, `dist/order.html` — команда, сертификат и конструктор заказа.
- `dist/v2.css`, `dist/v2.js`, `dist/v2-copy.js` — визуальная система второго варианта, взаимодействия и локализация.
- `dist/styles.css`, `dist/layout-refresh.css`, `dist/scale.css` — общие стили и стили портфолио.
- `scripts/build-v2-pages.mjs` — генерация главной, портфолио, услуг и контактов.
- `dist/data.js` — проекты, услуги и переводы.
- `dist/app.js` — карусель, фильтры и просмотр проектов.
- `dist/motion.js` — анимации, прокрутка и учёт reduced motion.
- `dist/assets/` — локальные фотографии, логотипы и шрифты.
- `server/lead-worker.mjs` — приём заявок и отправка в Telegram.
- `scripts/build-worker.mjs` — сборка Worker и статических файлов для Sites.
- `ASSET-SOURCES.json` — источники фотографий.
- `.openai/hosting.json` — настройки отдельного сайта Sites.

## Интеграции

Серверный маршрут `POST /api/custom-orders` проверяет изделия, контакт, фотографии и макет, затем передаёт заказ через Telegram Bot API в чат менеджера. Размеры баннеров можно ввести в метрах или сантиметрах. В составе заказа показывается предварительная сумма. Пожелания по материалам и бюджету передаются менеджеру для согласования. `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` хранятся в секретах Sites, не в репозитории. Если Telegram недоступен, сайт показывает ошибку и оставляет ссылку на ручное обращение через `https://t.me/colourway_CRM`. Заявки не записываются в базу сайта: история находится в чате Telegram. Маршрут `POST /api/leads` остаётся для совместимости со старыми клиентами.

Для будущих кнопок статуса в Telegram предусмотрен маршрут `POST /api/telegram/webhook` и дополнительный секрет `TELEGRAM_WEBHOOK_SECRET`. Вебхук можно включить после открытия сайта для публичного доступа: Telegram не сможет обратиться к частному сайту. Телефон, адрес, email и социальные ссылки взяты с действующего сайта ColourWay.

## Источники и права

Сведения о компании, направления услуг, фотографии и логотипы взяты с `https://colourway.uz/` по запросу пользователя. Авторские права на материалы принадлежат соответствующим правообладателям. Исходные адреса фотографий записаны в `ASSET-SOURCES.json`; логотипы — из каталога `/images/clients/` исходного сайта. Веб-шрифт Geometria подключён локально из CDNFonts. Исходные адреса начертаний приведены в `FONT-SOURCES.json`.

## Проверка

Проверяются синтаксис JavaScript, сценарии заказа, переключение языков и навигация между страницами. Для адаптивной вёрстки предусмотрены контрольные точки 960, 700 и 390 пикселей.

Этот проект создан как отдельная версия. Для переноса на `colourway.uz` потребуется доступ к хостингу действующего сайта.
