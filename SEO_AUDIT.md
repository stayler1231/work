# SEO-аудит до изменений

Срез исходного состояния: коммит `57840b3a933b0a2992658613e7ab0747eb8b6efd` (26 ноября 2026). Возможность отката: этот Git-коммит и версия Site 74.

## Архитектура и индексируемость

- Стек: статические HTML/CSS/JavaScript, сборка `scripts/build-worker.mjs`, Cloudflare Worker для заявок и раздача `dist/client` через `ASSETS`.
- Публичные маршруты: `/`, `/projects`, `/services`, `/about`, `/contact`, `/order`. Контент основных страниц уже присутствует в исходном HTML. Язык переключается JavaScript на тех же URL.
- Существуют технические HTML-варианты `ziynat-*` и `designs.html`. Они копируются в публичную сборку, что создаёт риск дублей.
- У восьми фактически описанных групп услуг есть секции на `/services`, но нет отдельных индексируемых страниц. Прочие предлагаемые в ТЗ категории частично пересекаются с этими группами.

## Проблемы по приоритету

| Приоритет | Наблюдение | Основание |
|---|---|---|
| Высокий | Нет sitemap.xml и robots.txt | Оба URL возвращали HTTP 404 на текущем Site. |
| Высокий | Нет canonical на индексируемых страницах | Проверены HTML в `dist/client`. |
| Высокий | Нет серверных языковых URL или hreflang | `lang="ru"` во всех HTML; перевод меняется клиентским скриптом. Индексировать такие версии как отдельные нельзя. |
| Высокий | Нет отдельных URL услуг | `/services/outdoor-advertising/` возвращал HTTP 404. |
| Средний | Нет JSON-LD на основных страницах | В HTML нет `application/ld+json`. |
| Средний | OG-разметка есть только частично на странице заказа; Twitter Card отсутствует | Проверены метатеги всех HTML. |
| Средний | Технические варианты могут индексироваться как дубли | `ziynat-*.html`, `designs.html` доступны в `dist/client`. |
| Средний | Много изображений без явных размеров в генерируемых внутренних страницах | Стабильность макета зависит от CSS. Большинство изображений уже WebP, ниже первого экрана часто используются `loading="lazy"`. |
| Низкий | Страница 404 хостинга не оформлена в стиле сайта | Неизвестный маршрут корректно возвращал HTTP 404. |

## Проверки и ограничения

- На Site проверены HTTP 200 для `/`, `/order`, `/services`; неизвестный маршрут возвращает 404. HTTPS работает.
- В репозитории есть тесты серверных заявок и сервис-воркера. Их запуск и проверка ссылок запланированы после изменений.
- Адрес `colourway.uz` указан в ТЗ, но текущая опубликованная площадка — `colourway.s7ayler1.chatgpt.site`. Владение доменом, DNS, Search Console, Analytics и Метрикой из исходного кода подтвердить нельзя. Не следует выдавать ненастроенный домен за рабочий canonical.
- Тексты услуг, фотографии и контакты берутся только из существующего проекта. Дополнительные услуги без подтверждённого описания не должны получать пустые индексируемые страницы.
- Значения Core Web Vitals и Lighthouse до изменений не замерены; без доступа к соответствующему браузерному инструменту сравнение баллов было бы недостоверным.
