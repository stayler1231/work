# Журнал запусков ПК

Приложение для Windows 10 и 11 показывает, когда запускалась Windows, когда начиналось выключение и какие перезагрузки были связаны со сбоями. Windows записывает эти события в системный журнал автоматически, даже если приложение закрыто.

## Запуск EXE

Откройте `dist/BootLog.exe` на 64-разрядной Windows 10 или 11. Эта версия использует встроенный Windows PowerShell и работает без установки Python. Можно перенести один EXE в любую папку.

## Запуск из исходного Python-кода

1. Установите [Python 3.10 или новее](https://www.python.org/downloads/windows/) с компонентом Tcl/Tk. Если используете установщик с опцией «Add Python to PATH», включите её.
2. Сохраните `Start.cmd` и `boot_log.py` в одной папке.
3. Дважды щёлкните `Start.cmd`. Если Windows сообщает об отказе в доступе к журналу, попробуйте запустить файл от имени администратора.

Выберите период от 7 до 365 дней. Щёлкните событие, чтобы увидеть его источник, номер записи и подробности. Кнопка «Сохранить CSV» выгружает события за выбранный период в файл, который можно открыть в Excel.

Время событий 41 и 6008 показывает, когда Windows зарегистрировала последствия аварийного отключения, обычно при следующем запуске. Точное время отключения может быть в подробностях события 6008, если Windows его сохранила. Доступная история зависит от размера системного журнала и его настроек очистки. Для длительного хранения сохраняйте CSV.

## Сборка EXE

Из корня репозитория на Linux с Go 1.24 выполните:

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w -H=windowsgui' -o dist/BootLog.exe windows/main_windows.go
```
